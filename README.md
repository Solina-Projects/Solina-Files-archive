# SolinaFM

فایل‌منیجر مینیمال اندروید با Material Design 3 (رنگ‌های پویا).

## امکانات
- پشتیبانی کامل از فارسی و راست‌به‌چپ (و انگلیسی)، تاریخ شمسی در حالت فارسی
- حافظه داخلی، کارت حافظه و USB؛ با فلش بالای صفحه، فهرست حافظه‌ها و میزان پر و خالی را ببینید
- نگه داشتن انگشت روی هر مورد: انتخاب؛ نوار بالا: کپی، برش، تغییر نام و منوی بیشتر (انتخاب همه، حذف، مشخصات)
- پوشه جدید، نمایش فایل‌های مخفی، بازخوانی

## گرفتن فایل APK
تب **Actions** ← آخرین اجرای **Build APK** ← پایین صفحه در **Artifacts** فایل `SolinaFM-debug-apk` را دانلود کنید.
