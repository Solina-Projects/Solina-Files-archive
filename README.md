# SolinaFM

فایل‌منیجر ساده برای اندروید.

## امکانات نسخه ۰.۱
- مرور پوشه‌ها و فایل‌های حافظه داخلی
- باز کردن فایل‌ها با برنامه‌های نصب‌شده
- ساخت پوشه، تغییر نام، کپی، انتقال، حذف و مشاهده مشخصات (با نگه داشتن انگشت روی هر مورد)

## گرفتن فایل APK
1. در همین صفحه گیت‌هاب روی تب **Actions** بزنید.
2. آخرین اجرای **Build APK** را باز کنید.
3. پایین صفحه در بخش **Artifacts** فایل `SolinaFM-debug-apk` را دانلود کنید.
4. فایل ZIP را باز کنید و `app-debug.apk` را روی گوشی نصب کنید.
